# Проверка тестовой версии

Проверено в текущей облачной машине: Node.js 24.19.0, Python 3.12.14, Chromium с программным WebGL-рендером. Все перечисленные команды фактически выполнены.

| Проверка | Результат |
| --- | --- |
| Чистая установка `npm ci --no-audit --no-fund` | Пройдена по сохранённому lockfile |
| `npm run verify:models` | SHA-256 геометрии, источники и вычисления 114 пространственных точек воспроизводятся |
| `npm run test` | 21 тест пройден |
| `npm run test:bot` | 9 тестов пройдено, Telegram API имитируется |
| `npm run build` | TypeScript и Vite проходят сборку |
| `npm run test:e2e` | 16 сценариев пройдено: компьютер и телефон |
| `BASE_PATH=/starosta-bo/ npm run build` и `E2E_BASE_PATH=/starosta-bo/ npm run test:e2e` | Сборка и все 16 браузерных сценариев проходят для пути GitHub Pages |
| `python3 scripts/import-models.py` | 50 исходных файлов заново скачаны с проверкой SHA-256 и Git blob ID; получен тот же итоговый массив |
| `npm audit --omit=dev --audit-level=high` | Уязвимостей в runtime-зависимостях не найдено |

Браузерные проверки контролируют фактическое количество отрисованных треугольников, выбор и изоляцию сторон костей, фильтры 8/14/22 костей, сборку/разборку, изменение камеры, связь 3D-метки с термином, поиск, оригинальные иллюстрации, завершение теста и локальное сохранение прогресса. Ни один из перечисленных тестов не пропущен.

Сохранённый `install_script` выполнен целиком: установка, проверка моделей, тесты, сборка и браузерные сценарии. `start_skill` содержит перезапуск статического сервера и проверку его готовности. Сохранение конфигурации само по себе не выполняет публикацию или проверку новой машины.

## Что не подтверждено

- GitHub Actions на удалённом репозитории и публичный HTTPS-сайт ещё не запускались; workflow и локальная имитация пути проверены. Нужны загрузка кода и включение Pages владельцем репозитория.
- Реальная работа Telegram-бота и развёртывание на bothost.ru требуют свежего токена, опубликованного URL и запуска процесса на хостинге. Секрет не включён в файлы. Для live-проверки предназначена команда `python3 main.py --check`.
- 92 структуры имеют перенесённые 3D-метки, остальные 134 доступны в каталоге без придуманных координат. Геометрическая регистрация и программные тесты не являются экспертной медицинской рецензией.
- Актуальная панель BotHost и первичный PDF FIPAT напрямую из этой среды недоступны из-за сетевой политики; ограничения описаны в README и ANATOMY.md.
- Стандартный Dockerfile для Python-бота подготовлен; сборка Docker-образа не выполнялась, для проверенного Python-процесса контейнер не требуется.

Небольшое предупреждение Vite о размере отложенного Three.js-модуля не является ошибкой сборки. Библиотека загружается отдельно; геометрия хранится локально в проекте и не зависит от внешнего 3D-CDN.
